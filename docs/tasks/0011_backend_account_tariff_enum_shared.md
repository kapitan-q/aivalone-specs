# Задача 0011: Реализация Tariff Enum в Shared Context

## Описание

Реализовать enum `Tariff` в Shared Context для унификации доступных тарифных планов во всей системе.

## Требования

- [x] Класс должен быть расположен в `src/Context/Shared/Domain/Model/Tariff.php`
- [x] Должен быть PHP 8.1+ enum (или классический класс для ранних версий)
- [x] Поддерживать значения: FREE, BASE, PRO, ENTERPRISE
- [x] Методы для работы с enum значениями

## Поддерживаемые тарифы

| Значение    | Код            | Описание           | Статус    |
|-------------|----------------|--------------------|-----------|
| FREE        | `FREE`         | Бесплатный тариф   | Активен   |
| BASE        | `BASE`         | Базовый тариф      | Активен   |
| PRO         | `PRO`          | Профессиональный   | Активен   |
| ENTERPRISE  | `ENTERPRISE`   | Корпоративный      | План      |

## Интерфейс

```php
class Tariff
{
    public static function fromCode(string $code): self
    
    public function code(): string
    
    public function equals(Tariff $other): bool
}
```

## Требования

- [x] `fromCode()` - создание из строкового кода
- [x] `code()` - возврат строкового кода
- [x] `equals()` - сравнение двух значений
- [x] Все значения должны быть доступны через константы

## Использование

```php
$free = Tariff::fromCode('FREE');
echo $free->code(); // 'FREE'
```

## Критерии готовности

- [x] Enum реализован с требуемыми методами
- [ ] Покрыт unit-тестами (минимум 4 теста)
- [ ] Документация актуальна

## Зависимости

Нет (базовый компонент Shared)
