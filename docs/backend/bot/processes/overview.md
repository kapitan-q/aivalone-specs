| ---------------------------------------------------------------- | ------------------------------------------------------ |
| [Handle Incoming Message](handle-incoming-message.md)            | Обработка входящего сообщения от мессенджера           |

| [Register Endpoint](register-endpoint.md)                        | Регистрация NotificationEndpoint при /start            |
| [Start Conversation](start-conversation.md)                      | Запуск диалога /start                                  |
