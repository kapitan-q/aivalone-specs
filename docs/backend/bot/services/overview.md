# Сервисы Bot Context

## Описание

Application-layer сервисы Bot Context обеспечивают бизнес-логику маршрутизации сообщений и управления диалогами.

## Сервисы

| Сервис                                                  | Описание                                               |
| ------------------------------------------------------- | ------------------------------------------------------ |
| [Router](router.md)                                     | Маршрутизация входящих сообщений к диалогам            |
| [ConversationRegistry](conversation-registry.md)        | Реестр доступных диалогов                              |
| [MessageSender](message-sender.md)                      | Отправка сообщений через адаптеры мессенджеров         |
