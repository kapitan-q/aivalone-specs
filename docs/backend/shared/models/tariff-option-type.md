# TariffOptionType Enum

## Описание

Enum `TariffOptionType` определяет тип значения, которое может хранить опция тарифа.
Используется во всех контекстах для унификации работы с типами опций тарифов.

## Доступные типы

| Значение       | Код             | Описание           |
|----------------|-----------------|-------------------|
| MAX_CONSTRAINT | `MAX_CONSTRAINT` | Максимальное количество (целое число) |
| BOOL           | `BOOL`          | Логический флаг (true/false) |
| TEXT           | `TEXT`          | Текстовое значение (строка) |

## Методы

### `fromCode(string $type): TariffOptionType`

Создание экземпляра из строкового кода.

- **Параметры**: `$type` — строка с типом опции (например, 'MAX_CONSTRAINT')
- **Возвращает**: Экземпляр `TariffOptionType`
- **Исключения**: `InvalidOptionTypeException` при невалидном типе

### code(): string

Возвращает строковый код типа.

Используется:

* в событиях
* в сериализации
* при передаче между сервисами
