# Обзор контекста Billing

## Назначение

**Billing Context** отвечает за управление тарифами, подписками пользователей и отслеживание их статусов. Он обеспечивает:

* управление доступными тарифами и их опциями (ограничениями)
* регистрацию и управление подписками пользователей
* продление подписок с отслеживанием истории
* отслеживание сроков действия подписок
* уведомление о скором истечении подписок
* предоставление лимитов пользователя для других контекстов
* интеграцию с другими контекстами (Account и Bot)

Контекст построен по принципам **DDD** и является автономной частью `Core Backend`, что позволит в будущем при необходимости выделить его в отдельный сервис.

## Основные функции

1. **Управление тарифами**

   * Определение доступных тарифов (FREE, BASE, PRO, ENTERPRISE)
   * Установка приоритета, цены и других параметров
   * Управление опциями (ограничениями) каждого тарифа
   * Пример: Тариф FREE имеет опцию "MAX_GROUPS" = 5

2. **Управление подписками**

   * Добавление подписки для пользователя с указанием периода (MONTH, YEAR)
   * Продление подписки (создание новой с ссылкой на предыдущую)
   * Удаление/отмена подписки
   * Автоматическое создание FREE подписки при регистрации пользователя
   * Генерация событий при изменении подписок

3. **Отслеживание сроков действия**

   * Проверка истекших подписок
   * Уведомления о скором истечении (7, 3, 1 день до истечения)
   * CLI команды для автоматической обработки расписаний

4. **Предоставление лимитов**

   * Query `GetUserLimits` для получения агрегированных лимитов пользователя
   * Используется другими контекстами для проверки прав доступа

5. **Интеграция с другими контекстами**

   * **Account Context** — обработка UserRegistered, создание FREE подписки
   * **Bot Context** — запрос лимитов пользователя через GetUserLimits Query

## Доменные модели (high-level)

| Модель                | Описание                                                            |
| --------------------- | ------------------------------------------------------------------- |
| **Tariff**            | AggregateRoot для управления тарифом, его свойствами и опциями      |
| **TariffOption**      | Опция (ограничение) тарифа, не существует без тарифа              |
| **UserSubscription**  | Запись о подписке пользователя на определенный тариф              |

## Основные сценарии использования

* Автоматическое создание FREE подписки при регистрации пользователя
* Добавление пользователю новой подписки с периодом (MONTH/YEAR)
* Продление подписки пользователя
* Удаление подписки пользователя
* Получение списка всех доступных тарифов и их опций
* Получение лимитов пользователя (для проверки прав в других контекстах)
* Проверка истечения подписок (автоматически через CLI)
* Отправка уведомлений о скором истечении подписки

## Взаимодействие с другими контекстами

| Контекст | Тип взаимодействия  | Примеры                                                      |
| -------- | ------------------- | ------------------------------------------------------------ |
| Account  | Синхронное, Events  | Получение userId, обработка UserRegistered → создание FREE   |
| Bot      | Синхронное (Query)  | Запрос GetUserLimits для проверки прав при командах          |
| Shared   | Зависимость         | AggregateRoot, базовые исключения, события, Enum            |

## Архитектурные ограничения

* Tariff является AggregateRoot и отвечает за свои опции (TariffOption)
* TariffOption не может существовать без Tariff
* UserSubscription хранит userId, tariffId, period и ссылку на предыдущую подписку
* У пользователя не может быть двух активных подписок на **один тариф**
* Пользователь может иметь активные подписки на **разные** тарифы (FREE + PRO)
* Все команды валидируют входные значения и конвертируют их
* SubscriptionService выполняет всю бизнес-логику управления подписками

## Структура контекста (файловая)

```
src/Context/Billing/
├── Domain/
│   ├── Model/              # Tariff, TariffOption, UserSubscription, ValueObjects
│   ├── Enum/               # SubscriptionStatus, SubscriptionPeriod
│   ├── Event/              # TariffUpdated, UserSubscriptionUpdated, SubscriptionRenewed, etc.
│   ├── Repository/         # Интерфейсы репозиториев
│   └── Exception/          # Исключения (TariffNotFound, InvalidSubscription и т.д.)
├── Application/
│   ├── Service/            # SubscriptionService
│   ├── Command/            # Command Handlers (AddUserSubscription, RenewSubscription, RemoveSubscription)
│   ├── Query/              # Query Handlers (GetTariffList, GetUserLimits)
│   └── Event/              # Event Handlers (UserRegisteredEventHandler)
├── Infrastructure/
│   ├── Persistence/        # Doctrine Entities, Repositories, DataMappers
│   └── Cli/                # CLI Commands (check-subscription-expiration)
└── Presentation/
    └── Http/
        └── Controller/     # REST контроллеры (TariffController, SubscriptionController)
```
